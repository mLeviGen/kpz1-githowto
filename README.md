# Лабораторно-практична робота №1
## Мета
Ознайомитися з базовими командами та принципами роботи з системою контролю версій Git шляхом проходження інтерактивного навчального курсу. Сформувати практичні навички використання Git у консольному середовищі для виконання основних операцій.

## Виконана робота 
В рамках першого етапу було повністю пройдено першу частину інтерактивного курсу «Git How To» (кроки 1–30). Під час навчання було детально вивчено життєвий цикл репозиторію: від ініціалізації та перших коммітів до складніших операцій, таких як скасування змін, злиття гілок та синхронізація з віддаленими репозиторіями.

Усі результати проходження кожного етапу задокументовано у вигляді скриншотів, які розміщені у папці screens.
